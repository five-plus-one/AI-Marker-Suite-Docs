# 油猴存储页卡住怎么办

好分数等平台的原站阅卷页可以打开，油猴也显示 AI-Marker-Suite 已启用，但右下角没有助手入口。打开脚本的「存储」页时，页面一直转圈、无法编辑，或浏览器提示「网页无响应」。遇到这组现象，先点击「退出网页」，再根据有没有紧急阅卷任务选择下面的处理方式。

## 为什么会卡住

阅卷时间较长时，诊断日志和评阅历史会逐渐累积。油猴在启动脚本和打开「存储」页时都要读取这些数据。数据量较大时，油猴可能无法把数据交给脚本，存储编辑器也可能无响应。

新版将诊断日志合计控制在 4 MiB 以内，先淘汰最早的日志。更新后，打开阅卷页并允许助手启动，脚本才能整理已有日志。如果油猴仍然无法启动脚本，按下方步骤备份和恢复。

## 现在要继续阅卷

1. 打开另一个浏览器，或在 Chrome 右上角点头像，添加一个个人资料。
2. 按[油猴脚本安装指南](./userscript-install)安装扩展并启用用户脚本，再[安装 AI 批改助手正式版](https://auto-update.aimarking.five-plus-one.com/ota/ai_marker.user.js)。
3. 登录原阅卷平台，重新连接自己的 AI 账号或供应商。已有助手配置文件时，在「批改配置 → 数据 → 配置管理」选择「导入配置」。
4. 打开一份答卷，用试改模式核对填分和原站保存，再继续阅卷。

## 备份并恢复原浏览器

1. 从油猴图标重新打开「管理面板 → 实用工具」。如果缺少「实用工具」页，在油猴「设置」把配置模式切到「初学者」或「高级」，再回来。
2. 在「ZIP」区域选择「导出」，勾选包含脚本存储，保存到本机。这个备份可能包含账号配置和学生作答，请通过学校认可的方式联系支持。需要备份答卷图片时，可在助手能打开的对应阅卷平台，通过「评阅历史 → 材料包 ZIP」单独导出。
3. 由支持人员在备份的副本里清理 AI 批改助手的旧诊断日志，并核对评阅历史与评分方案。优先使用问题发生后刚导出的 ZIP，以保留最近保存的数据。
4. 拿到处理后的 ZIP 后，从「管理面板 → 实用工具 → ZIP → 选择文件」导入。按提示选择 AI-Marker-Suite 和脚本存储，然后刷新阅卷页，核对原方案和历史是否可用。 [油猴官方导入与导出说明](https://www.tampermonkey.net/faq.php?q=Q106)

若「实用工具」也打不开，先用独立浏览器继续阅卷，并联系[帮助与支持](/support)。提供浏览器、油猴和脚本版本，以及「网页无响应」的截图即可开始排查。
