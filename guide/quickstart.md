# 快速上手

打开一份待阅答卷，连接批改服务，为当前题目保存方案，再试改一份答卷。

## 前置条件

- 已安装 Tampermonkey 扩展和 AI 批改助手脚本（详见 [安装教程](./installation)）
- 拥有对应平台的教师账号和待阅任务。可在[支持平台](/platforms/)查询入口与适用任务。

<span id="第一步-获取-api-密钥" class="fp-anchor-alias" aria-hidden="true"></span>

## 第一步：配置 AI 服务

进入阅卷平台的待阅任务，打开一份答卷，等答题卡和给分区加载完成。首次使用时，助手会显示「连接批改服务」。如果已关闭引导，也可以从页面右下角的「批改配置」进入「AI → 供应商与模型」连接服务。

### 使用五加一账号连接

1. 在「连接批改服务」中点击「登录五加一账号」。

   ![连接批改服务窗口，提供登录五加一账号和使用已有 API 密钥两个入口](https://img.five-plus-one.com/i/2026/11/22/312d16de1e824c8a.png)

2. 在新标签页的「用户名 / 邮箱」一栏输入用户名或邮箱，点击「登录」并按提示完成登录。还没有五加一账号时，点击下方的「注册」，按提示创建账号。

   ![五加一账号登录页，填写用户名或邮箱，也可点击注册](https://img.five-plus-one.com/i/2026/11/22/cca6ab5087153888.png)

3. 按页面提示完成授权。看到「授权已完成」后，切回原来的阅卷标签页，等待助手测试批改线路。

   ![连接 AI 批改助手页面提示授权已完成，请返回阅卷页](https://img.five-plus-one.com/i/2026/11/22/055f1eeada50d387.png)

4. 在「五加一账号已连接」窗口看到「批改服务已就绪」后，点击「配置批改方案」。

   ![五加一账号已连接，批改服务测试通过，可配置批改方案](https://img.five-plus-one.com/i/2026/11/22/83ae76e2fd36f6b7.png)

   如果提示余额不足，点击「查看余额与充值」，到账后回到阅卷页点击「重试线路测试」。详见[余额与充值](../config/api-setup#余额与充值)。

<span id="第二步-配置-api-密钥" class="fp-anchor-alias" aria-hidden="true"></span>

### 使用 API 密钥

1. 在「连接批改服务」中点击「或使用已有 API 密钥」。
2. 在「输入 API 密钥」页面粘贴已有的 5plus1API 密钥。需要创建密钥时，点击「获取 API 密钥」，在打开的密钥管理页创建并复制密钥，再返回阅卷页。
3. 点击「验证并继续」，验证通过后进入「配置方案」。

使用其他兼容供应商或需要切换线路时，参阅 [AI 接口配置](../config/api-setup)。识别手写答案需要支持图片输入的模型。助手可免费安装，AI 服务按用量计费。

## 第二步：配置批改方案

1. 在「配置方案」中填写「配置方案名称」，例如「数学第 21 题」。在「批改模式」中选择「试改」，然后点击「继续」。

   ![配置方案窗口，填写方案名称后选择试改模式](https://img.five-plus-one.com/i/2026/11/22/51131b49980095ba.png)

2. 在「选择批改工作流」中选择「快速批改（推荐）」，然后点击「继续」。复杂题目可以按需选择「高精模式」或「双评模式（推荐）」。[了解批改工作流](../config/workflow)。
3. 在「填写批改资料」中点击对应的「编辑」，填写参考答案、评分标准，按需补充题目内容。填写或核对满分，若页面列出多个小题，逐一核对每小题的满分。点击「保存并继续」。
4. 看到「方案已保存」后，点击「查看方案」，确认当前试题使用了所选方案。如果先选了「稍后填写」，可点击「补充批改资料」，补齐后点击「保存并启用」。确认后返回答卷。

## 第三步：开始批改

1. 核对待阅答卷、题号、满分和给分步长。
2. 点击右下角的「AI 批改」。评分完成后，试改模式会暂停，等待你核对识别到的作答、得分和评分依据。
3. 核对无误后点击「确认提交」，并按阅卷平台的提示完成提交。如果评分有误，可以先点「纠错」，修正分数并按需调整评分标准。

## 填写评分标准（推荐）

把每个得分点和对应分值写清楚，试改时就能逐项核对给分是否符合要求。

| 字段 | 说明 | 示例 |
|------|------|------|
| **题目内容** | 试卷上的原始题目 | 请举例分析本文的两种写作手法。 |
| **参考答案** | 答题要点 | 运用比喻描绘江面，运用拟人表现春风。 |
| **评分标准** | 各得分点及其分值 | 满分 5 分。每正确指出一种手法并举出对应例子得 2 分，分析其表达效果得 1 分，表达效果一项最多得 1 分。 |

评分有偏差时，可在「批改配置」中调整[评分规则](../config/rubric)，再试改几份答卷。

## 切换批改模式

试改后，可以在「批改配置 → 批改 → 运行模式」调整提交方式，点击「保存并启用」使设置生效。

- **普通模式**会显示确认窗口，并按倒计时设置提交。
- **试改模式**逐份等待教师确认，适合核对评分标准。
- **无人值守模式**会自动提交，适合确认评分效果后连续批改。

需要两次独立评分时，可在「AI → 批改工作流」选择双评工作流，并继续使用试改逐份核对。详见[批改模式](../modes/)。
