# 双评模式

双评模式是一种高精度批改方式，在同一份答卷上独立评分两次，分差超过阈值时再请仲裁模型评判。适合对评分准确性要求较高的场景，如重要考试、竞赛评卷等。

## 工作原理

```
试卷 → 主模型评分 ─┐
                    ├→ 比较分差
试卷 → 副模型评分 ─┘
                    │
          ┌─────────┴─────────┐
          ↓                   ↓
      分差 ≤ 阈值         分差 > 阈值
      按合并策略给分        启动仲裁模型
     （共识结果）         （仲裁结果）
```

1. **并发评分**：主模型和副模型同时对同一份试卷独立评分
2. **分差比较**：计算两个分数的差值
3. **共识判定**：如果分差 ≤ 阈值（默认 2 分），按[双评合并策略](/config/workflow#双评合并策略)给分，默认平均后四舍五入到评分梯度
4. **仲裁判定**：总分分差超过阈值时启动仲裁。启用「分小问作答核对」时，任一小问分差超过阈值也会启动仲裁

## 配置方法

### 使用内置双评工作流

在「批改配置 → AI → 批改工作流」选择「双评模式(高精度)」，点击「保存并启用」。内置工作流的设置如下。

| 配置项 | 默认值 |
|--------|--------|
| 主模型 | aimarker-fast（不思考） |
| 副模型 | aimarker-fast（不思考） |
| 仲裁模型 | aimarker-pro（默认深度） |
| 分差阈值 | 2 分 |

### 自定义双评工作流

1. 在「AI → 批改工作流」点「编辑」或「新建」
2. 勾选「启用双评模式」
3. 配置：
   - **副模型**：选择供应商、模型和思考链深度
   - **仲裁模型**：建议使用更高精度的模型（如 aimarker-pro）
   - **分差阈值**：超过此值时仲裁，默认 2 分。另可选择阈值内的合并策略
4. 保存工作流，选择为「当前工作流」，并点击「保存并启用」。

### 配合批改模式使用

在「批改 → 运行模式」选择如何提交双评结果。下表为默认提交设置。

| 组合 | 说明 |
|------|------|
| 双评 + 普通模式 | 双评完成后 5 秒倒计时提交，可查看双评详情后确认 |
| 双评 + 试改模式 | 双评完成后等待教师确认，可纠错 |
| 双评 + 无人值守 | 双评完成后 1 秒自动提交，适合大批量 |

## 双评结果详情

在提交窗口可核对主、副模型的分数和合并或仲裁结果。评分说明随[输出模式](/config/#输出模式)显示。

### 共识结果（分差 ≤ 阈值）

- 双评结果：分差、判定（共识）
- 老师 A：得分、评分依据、分数计算
- 老师 B：得分、评分依据、分数计算

### 仲裁结果（分差 > 阈值）

- 双评结果：分差、判定（⚠ 三评仲裁）
- 老师 A：得分、评分依据、分数计算
- 老师 B：得分、评分依据、分数计算
- 仲裁结果：仲裁得分、仲裁分析

### 历史记录中的双评

评阅历史中每条双评记录都会显示：

- 双评标签（共识/仲裁）
- 详情抽屉中展示完整的老师 A/B 评分和仲裁结果
- 导出包含实际保留的双评详情

## 使用建议

1. **首次使用**：建议先用「试改模式 + 双评」组合，观察两个模型的评分差异
2. **阈值设置**：对于满分 100 分的题目，阈值 2 分是比较合理的；满分较小的题目可以适当降低。阈值可设为 0，此时两模型给分完全一致即可形成共识，有分差时进入仲裁
3. **模型选择**：主副模型建议使用不同模型，交叉验证效果更好；仲裁模型建议使用精度最高的
4. **调用费用**：一般先发出两次评分请求，有仲裁时再发一次。答卷核对和重试也可能增加调用，实际费用按各模型的计费规则计算。

## 常见问题

### 双评模式比普通模式慢多少？

主、副模型同时评分，等待时间取决于返回较慢的一方。进入仲裁时，还要等待仲裁模型返回。

### 两个模型都失败了怎么办？

任一模型结果缺失时会暂停批改并提示核对。偶发格式不完整时，助手会重试对应模型；仍无法得到完整双评结果时，请检查服务状态和模型回答后继续。

### 可以只用双评不用仲裁吗？

可以把阈值设为本题满分，使有效分数的分差始终在阈值内，按合并策略给分。阈值设为 0 时，出现分差就会进入仲裁。

### 仲裁模型和主副模型可以是同一个吗？

可以在工作流中选用同一个模型。内置双评工作流的主、副模型都用 aimarker-fast，仲裁用 aimarker-pro。
