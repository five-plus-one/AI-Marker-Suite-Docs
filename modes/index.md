# 批改模式

在「批改配置 → 批改 → 运行模式」选择普通模式、试改模式或无人模式，再点击「保存并启用」。运行模式决定何时提交；单模型或双评由「AI → 批改工作流」决定。

::: info 移动端用户
如果你在手机上浏览，可以点击页面左上角的 **☰ 菜单按钮** 展开侧边目录，在各章节之间切换。
:::

## 模式对比

| | 普通模式 | 试改模式 | 无人模式 |
|---|---|---|---|
| 适合场景 | 日常阅卷 | 首次配置、逐份确认 | 已核对方案后的连续批改 |
| 默认提交 | 5 秒倒计时，可暂停或立即提交 | 教师确认后提交 | 1 秒倒计时 |
| 纠错入口 | 提交窗口「分数有误」 | 提交窗口「分数有误」 | 需人工核对时按提示在平台处理 |
| 重试设置 | 其他模式的请求重试次数 | 其他模式的请求重试次数 | 无人模式每步最多重试次数 |

开启[批改节奏](/config/#批改节奏-实验性)可调整普通和无人模式的提交等待时间。三种运行模式都可以搭配[双评工作流](./dual)。

## 题号变化时暂停

在「批改 → 答卷校验」中，默认开启「填分前校验答卷一致性」，防止在等待模型期间换卷后把分数填到另一份答卷。智学网和好分数还可开启「题号变化时暂停批改（实验性）」，默认关闭。

开启后，脚本记录开始批改时的题号、评分项与小题满分。同一道题切换到下一份答卷时继续批改；平台切换题号或评分项时暂停当前批改，并提醒核对评分方案。请确认当前题目、参考答案和评分标准，再点击继续。

页面刷新后也需要先核对题目再重新开始。暂未读到完整题号时，请等待阅卷页面加载；如果检测不正确，请联系作者适配。

::: tip 如何选择？
- **第一次使用**：先用试改模式，核对作答、分数和给分依据后再切换
- **日常少量批改**：普通模式，每份试卷都有确认机会
- **大批量**：先用试改核对方案，再用无人模式按目标份数批改
- **高精度要求**：双评模式，两个模型交叉验证，适合重要考试
:::
