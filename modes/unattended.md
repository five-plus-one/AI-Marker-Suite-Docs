# 无人值守模式

无人值守模式在结果可提交时连续批改，适合已经用试改核对过的批量阅卷任务。遇到需要教师确认的情况时会暂停。

## 工作流程

1. 核对当前题目和方案，点击「AI 批改」。
2. 助手读取当前答卷，按工作流识别并评分，再把有效分数填入页面。
3. 默认倒计时 1 秒后提交。开启[批改节奏](/config/#批改节奏-实验性)后，使用为无人模式设置的等待区间。
4. 确认提交后，等待下一份答卷加载。达到目标份数或需要人工核对时暂停。

## 核心特性

- 读取答卷、评分、填分、提交和等待下一份时，遇到可恢复的问题会按环节重试。
- 批改中的悬浮按钮显示「自动批改中…」，可点击暂停。处理好提示的问题后，点「继续批改」。
- 可按方案设置需要核对的答卷如何处理，以及是否保存无法辨认的原卷供复核。

## 自动重试配置

在「批改配置 → 自动化 → 自动重试」中设置，完成后点击「保存并启用」。

| 配置项 | 默认值 | 用法 |
|---|---|---|
| 无人模式每步最多重试次数 | 5 | 可设 0～5。读取答卷、评分、填分及换卷等环节分别计算。设为 0 时关闭这些环节的自动重试 |
| 其他模式的请求重试次数 | 3 | 可设 0～5，适用于普通和试改等模式的模型请求。首次请求另计。服务繁忙或出错时，这类重试最多 2 次，仍受所填总次数限制 |
| 超时时也重试 | 开启 | 适用于模型请求超时。关闭后仍可对空响应、回答未完整结束等可恢复情况重试 |

无人模式的评分环节会一起计算模型请求失败、切换备用线路、回答截断和重评等使用的重试次数。常见重试按 5 秒、10 秒、15 秒等间隔逐次等待。等待平台确认或换卷有各自的等待条件。普通和试改按各模型的请求计数，启用双评、仲裁或额外识别时仍会按流程发出相应的请求。

超时后，AI 服务仍可能在处理请求。重试可能产生额外费用，可按需关闭「超时时也重试」。

## 答卷核对与待复核

在同一「自动重试」区，可按方案开启下列实验性选项。

- **作答状态核对**默认关闭。开启后，当模型报告无法辨认、对是否作答的判断前后矛盾，或给空白卷正分时，要求核对。
- **配图作答核对**默认关闭。题目、答案或评卷标准带参考配图时，先单独识别学生作答，再据此核对评分。在评分前会增加一次识别请求。若同时开启分小问作答核对，助手会优先逐问识别。
- **分小问作答核对**默认关闭。先识别每问作答，再逐问评分。平台只有总分框时，请先[填写各小问题号和满分](/config/sub-questions#与单题模式的切换)。

遇到需要核对的答卷时，当前方案未选定处理策略就会暂停。已有方案继续沿用已保存的策略。选择自动复查或直接重试后，评分环节还有重试次数时才会执行。可以在「无人模式遇到需核对的答卷」中选择下列策略。

| 选项 | 遇到需要核对的答卷时 |
|---|---|
| 暂停，人工核对（默认） | 停在当前答卷，交给教师核对 |
| 复查原卷后重评（实验性） | 复查确认空白后按 0 分继续。确认有作答后重新评分。无法确认时暂停 |
| 直接重试评分（实验性） | 重新请求评分。重试用尽仍需核对时暂停 |

**保存无法辨认答卷供复核**默认关闭。开启后，无法辨认且需人工核对的答卷会暂停，并将原图和当时的评分方案保存到「评阅历史」的「待复核」记录。请在阅卷平台核对和给分，再到历史记录点击「完成复核」。

「允许待复核数量」默认 5，可设 1～50。达到上限后仍可批改可评分的答卷，遇到需要新增记录时先完成已有复核。原图会保留到完成复核，存储空间不足时按提示处理。

## 批阅份数与达标自动暂停

1. 在「自动化 → 批阅份数」勾选「启用批阅份数限制」，填入「目标批阅份数」，再保存。默认关闭。
2. 成功提交后计入进度，达到目标自动暂停。调整或关闭限制并保存会重置计数。
3. 达标后点击悬浮按钮「继续批改」，按需要选择：
   - **继续批阅**会继续本次批改，跳过已达到的份数限制。
   - **不再批阅**会保持暂停。
   - **重置批阅进度（从 0 开始）**会清零后按原目标继续。

此设置也适用于普通模式和试改模式。智学网考试阅卷如需在完成本题分配量后继续多阅，可在「自动化 → 智学网」开启对应选项。平台允许多阅时继续领取本题答卷，达到批阅目标或需要换题时停止。该选项默认关闭。

## 启用方式

在「批改配置 → 批改 → 运行模式」选择「无人模式」，点击「保存并启用」。确认阅卷页面停在要批改的题目，再点击右下角「AI 批改」。

## 错误处理

暂停后先看页面提示，核对当前答卷、平台进度或服务状态，再决定是否继续。

<span id="ai-识别失败" class="fp-anchor-alias" aria-hidden="true"></span>

### AI 识别失败 / 分数解析失败

模型结果缺少可用分数时，助手会在评分环节剩余次数内重新评分。作答无法辨认或需要核对时，按[答卷核对策略](#答卷核对与待复核)处理。若持续读不到有效分数，请用试改核对图片、工作流和评卷标准。

<span id="网络错误" class="fp-anchor-alias" aria-hidden="true"></span>

### 瞬态错误（超时 / 空响应 / 流式未结束）

服务暂时未响应、返回空内容或回答中断时，助手按无人模式的评分环节重试次数等待后再试。若关闭了「超时时也重试」，模型请求超时后按提示处理。

### HTTP 5xx / 429

服务暂时出错（5xx）或繁忙限流（429）时，无人模式在评分环节剩余次数内重试。余额不足时，请先到对应服务商查看余额并充值。

### 403 错误

如果答题卡图片访问受限导致页面自动刷新，请重新核对当前题目、方案和阅卷进度，再手动开始批改。必要时重新登录阅卷平台。

### 所有试卷批改完成

读不到答题卡或下一份加载超时时，先到平台核对剩余答卷。提交结果不明确时，助手会先检查阅卷页面是否已换到下一份。若仍无法确认，请先查平台的阅卷记录，再继续批改。

## 安全建议

### 推荐的使用流程

先用[试改模式](./trial)检查几份不同得分和作答情况的答卷。对照原图核对给分，按需补充评卷标准。确认方案后，切换到无人模式并设置合适的批阅份数。

### 监控建议

通过悬浮按钮、批阅进度和平台记录检查当前状态。切换任务前先暂停，核对新题的资料、满分和步长后再开始。

## 与其他模式的对比

| 操作 | 普通模式 | 试改模式 | 无人模式 |
|---|---|---|---|
| 默认提交 | 5 秒后提交，可立即提交 | 等待教师确认 | 1 秒后提交 |
| 暂停批改 | 可用悬浮按钮暂停，也可暂停提交倒计时 | 可用悬浮按钮停止本轮处理 | 可用悬浮按钮暂停 |
| 调整本卷评分 | 在提交窗口纠错 | 在提交窗口纠错 | 需要人工核对时，按提示在平台处理 |

## 适用场景

同一道题有多份待阅答卷，并且已经用试改确认当前工作流和评卷标准时，可用无人模式分批完成。
