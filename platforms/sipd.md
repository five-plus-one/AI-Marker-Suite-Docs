# 上进教育服务云平台（智慧上进）

## 平台简介

江西上进教育服务云平台（智慧上进）是一个在线阅卷平台，与[威科姆（悦卷通）](/platforms/weicom)使用同一套阅卷系统，jQuery 传统页面架构，答题卡图片托管在阿里云 OSS 上（按题裁剪）。

- **阅卷地址**: `https://www.sipd.cn/mark/v6/view/...`

## 技术特点

- **前端框架**: jQuery + ASP.NET WebForms 传统页面
- **图片渲染**: `<img>` 标签（阿里云 OSS 托管，按题裁剪，带安全 token）
- **分数输入**: 分数输入框（`.ipt_score`）+ 满分/零分快捷按钮
- **打分模式**: 键盘打分 / 鼠标打分 / 分步骤打分三种模式（脚本适配键盘模式）
- **特殊功能**: 0 分确认弹窗、自动提交选项

## 使用方法

### 1. 安装脚本

安装 AI 批改助手最新版本。

### 2. 打开阅卷页面

登录上进教育服务云平台，进入阅卷页面。页面 URL 应包含 `/mark/v6/view/` 路径。

页面结构如下：

- **中间**: 答题卡图片（`#imageFullScreen`，OSS 裁剪图）
- **右侧**: 打分面板（分数输入框 + 满分/零分按钮 + 提交按钮）

### 3. 使用 AI 批改

1. 脚本会自动检测阅卷页面，显示 AI 批改按钮
2. 点击按钮开始 AI 批改
3. AI 会自动识别答题卡图片、评分
4. 用户确认后，脚本将分数填入输入框并提交

## 平台特殊处理

### 0 分确认弹窗

平台在打 0 分时会弹出确认对话框（`#zeroCheckModal`）。脚本会自动点击确认按钮（`#btn_0_ok`），避免连续批改时被打断。取消勾选「0 分确认」选项后平台不再弹框。

### 换卷检测

提交后平台通过 `data-stu` 属性标识学生答卷切换（旧值 → 0 → 新值），脚本以此判断下一份已就绪，自动继续批改。

### 方案绑定

任务标识使用页面路径 + 小题 key，换学生、刷新页面均稳定，绑定评分方案后自动切换，不重复弹出引导。
