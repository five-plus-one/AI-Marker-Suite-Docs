# 正确阅卷

## 平台简介

正确阅卷 是基于 jQuery + layui 的传统阅卷平台。

- **阅卷地址**: `https://www.yuejuan.com`
- **评阅页面**: 路径 `/markPaper/detail/{题目ID}/{答卷ID}`

## 技术特点

- **前端框架**: jQuery + layui（传统多页，无 SPA 框架）
- **图片渲染**: `<img class="studentAnswerImg">`（外层可缩放/拖拽，不影响脚本取原图）
- **分数输入**: 打分板点击式（`#scoreItemBox` 的 `div[data-score]`，0..满分）+ 小键盘输入框（`#inp_singleTestScore`）
- **分数提交**: 点击「提交分数」按钮（`#submitScoreBox` 内）
- **满分/零分**: 打分板顶部「满」「零」快捷按钮（`data-score` 属性）
- **翻卷检测**: **靠图片 URL 文件名哈希变化**判定翻卷（每份答卷图片路径不同）

## 使用方法

### 1. 安装脚本

安装 AI 批改助手最新版本。

### 2. 打开评阅页面

登录正确阅卷平台，进入教师阅卷页（路径含 `/markPaper/detail/`）。页面结构：

- **左侧**: 答题卡呈现区（`#stuAnswerShowBox`，支持缩放/拖拽）
- **右侧**: 打分板面板，含题号+满分显示（如「9(6分)」）、打分键盘（0..满分）、小键盘输入框、「提交分数」按钮

### 3. 使用 AI 批改

1. 脚本自动检测批改页面，右下角显示 **AI 批改** 按钮
2. 点击开始批改，AI 识别答题卡并评分
3. 确认后脚本填入分数并提交，自动翻到下一份

## 注意事项

- **填分与提交分两步**：脚本先把分数写入小键盘输入框供你预览，确认后才点击打分板按钮（同步平台内部状态）并点「提交分数」——不会跳过你的确认环节
- 脚本点击打分板后若检测到已自动翻卷（平台行为变化时），会**跳过「提交分数」按钮**，避免给下一份误打分
- 打分板只有整数分值；小数分（如 3.5）走小键盘输入框兜底
- 页面上 layui 自绘下拉框的 `.layui-input` 是只读触发器，脚本不会误当分数框
- 「自动提交」「鼠标右键提交」是平台自带开关（默认关）。开着「自动提交」时键盘输入+Enter 会立即交卷，不影响脚本流程，但手工操作时注意

## 常见问题

**Q: 方案绑定（绑定到当前试题）是如何识别题目的？**
A: 脚本取 URL 中的题目 ID 段（`/markPaper/detail/{题目ID}/...`，与答题卡图片路径中的目录段一致）加题号标签（如「9(6分)」）作为任务标识。换学生答卷不会变，换题才会变——所以同一道题的方案能跨学生沿用。

**Q: 提交后翻卷检测不准？**
A: 脚本靠图片 URL 文件名哈希变化判定翻卷。若某平台版本改为缓存导致路径不变，会在答卷一致性校验处拦截并提示人工核对。

**Q: 小数分填不进打分板？**
A: 打分板本身只有整数按钮。脚本对小数分自动改用小键盘输入框填入，平台接受输入框值提交。

**Q: 分数输入框看不到 AI 填的分？**
A: 脚本通过原生 setter 赋值并派发 input/change/blur 事件（layui 需要），分数会显示在「题号(满分)」旁的输入框中，等待你确认提交。
