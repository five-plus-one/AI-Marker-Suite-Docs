# 睿芽考试服务云平台

## 平台简介

睿芽考试服务云平台（上海睿芽教育科技）采用 OnlyETS CampusManage/MarkClient 架构，与[恒佳考试服务云平台](/platforms/yuejuan51)、威科姆（悦卷通）同厂商代码。

- **阅卷地址**：`http://ruiya.onlyets.com`
- **批改页面**：`/mark/v6/view/<32位GUID>`
- **技术栈**：ASP.NET WebForms + jQuery + Bootstrap + iCheck

## 技术特点

- **答题卡**：`#imageFullScreen`，阿里云 OSS 题块裁剪图（带 `data-stu` 学生标识）
- **多小题评分**：`#panelKey` 下每小题一个 `input.ipt_score`，满分取「<= N」提示（支持小数）
- **提交**：「提交(Enter)」按钮对接平台 `Mark.submitKeyboard` 语义，直接读输入框取值
- **翻卷检测**：**密号 + data-stu 学生标识 + 图片路径**三重强信号；「输入框清空」仅作弱信号兜底并告警
- **回评识别**：`#reviewPanel` 面板可见性判定（页头常驻「回 评」链接不作判据）
- **弹窗处理**：0 分确认弹窗自动确认；「阅卷小提示」自动关闭

## 使用方法

### 1. 安装脚本

安装 AI 批改助手最新版。

### 2. 进入批改页面

登录睿芽 → 考试任务列表点「开始阅卷」进入批改页（地址含 `/mark/v6/view/`）。

### 3. 使用 AI 批改

1. 脚本自动检测批改页面，右下角显示 **AI 批改** 按钮
2. 首次使用完成 API 密钥与方案配置
3. 点击开始批改；填分前适配器会自动取消「自动提交」勾选、必要时切回键盘打分模式，**提交时机由脚本接管**

## 注意事项

- 仅支持**键盘打分模式**：分步打分模式不支持自动批改（不会显示批改入口）；鼠标打分模式会在填分时自动切回键盘模式
- 0 分卷会弹「零分确认」，适配器自动点确定；「阅卷小提示」弹窗自动关闭
- 该站仅 http 明文部署（https 证书无效），脚本匹配规则已用通配协议覆盖

## 常见问题

**Q: 填分后分数被平台清空/抢先提交？**

平台「自动提交」勾选时可能在分数录入后抢先交卷。适配器填分前会自动取消该勾选；若手动重新开启请留意。

**Q: 换卷检测会不会误判？**

密号与 `data-stu` 均为每生一换的强信号；仅当两者与图片路径均无变化时才依赖「输入框清空」弱信号兜底，并在控制台输出告警。
