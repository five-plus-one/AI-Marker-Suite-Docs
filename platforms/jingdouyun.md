# 精斗云(大数据精准教学)

## 平台简介

精斗云（大数据精准教学系统）是 AngularJS 1.x + jQuery 构建的 hash 路由单页应用，按题批阅（一次一题）。

- **阅卷地址**：`https://exam.wxy100.com`
- **批改页面**：`#!/testCenter/paperMark?examId=...&itemid=...`（地址含 `paperMark`）

## 技术特点

- **答题卡**：`#imgBox` 内按题渲染图片，支持**多图 / 合并图**两种模式
- **评分**：单分数框 `input#topic`（ng-model 绑定）+ 打分板按键；适配器直接写入模型值并触发校验
- **提交**：「保存」按钮（`markSave`），提交前平台校验模型值
- **翻卷检测**：图片 URL 带随机缓存参数（`?r=`），检测时**剥离缓存参数只比路径**
- **任务标识**：URL 的 `examId + itemid`（题目维度，学生切换不变，方案按题复用）

## 使用方法

### 1. 安装脚本

安装 AI 批改助手最新版。

### 2. 进入批改页面

登录精斗云 → 考试中心进入阅卷 → 批改页（地址含 `paperMark`）。

### 3. 使用 AI 批改

1. 脚本自动检测批改页面，右下角显示 **AI 批改** 按钮
2. 首次使用完成 API 密钥与方案配置（切题后会提示重新绑定）
3. 点击开始批改；填分前适配器会**自动取消「自动提交」开关**，提交时机由脚本接管

## 注意事项

- 「自动提交」勾选时平台可能在分数录入后抢先交卷——适配器填分前自动取消勾选（与九科星作业同款防护）
- 按题批阅：一次只批一个题目，切换题目后任务标识变化，会提示绑定对应方案
- 图片缓存参数随机变化不影响翻卷判定（只比路径）

## 常见问题

**Q: 提交后没有翻到下一份？**

平台保存后自动加载下一份；若分发未完成或任务批完，适配器会暂停并提示，可人工检查任务状态。

**Q: 换题后弹出「绑定方案」引导？**

任务标识按题目维度（examId + itemid）区分，换题视为新任务，为不同题目绑定各自的方案属于预期行为。
