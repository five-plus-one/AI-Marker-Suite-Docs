# 鑫考(内网版)

鑫考(内网版)是 AI 批改助手 v1.21.12.4 新增支持的阅卷平台，运行在内网裸 IP 的 `/biluo/display.jsp`，与公网版[鑫考](/platforms/xinkao)（`/Marking/DisPlay`）是两套完全不同的系统。

::: warning 与公网版鑫考的区别
两者同名但 DOM 结构、满分来源、提交机制、URL 结构完全不同，脚本会根据路径和 DOM 特征自动加载对应适配器，无需手动切换。
:::

## 支持的页面

- `*://*/biluo/*` — 鑫考网上评卷系统（内网裸 IP 部署，如 `http://10.x.x.x/biluo/display.jsp`）

::: tip 内网部署说明
平台部署在单位内网，访问地址为裸 IP（默认 80 端口，无端口号）。脚本通过**路径特征 + DOM 特征**联合识别平台，不依赖固定 IP。
:::

## 技术特点

鑫考(内网版)基于 jQuery 传统页面构建：

| 特性 | 说明 |
|------|------|
| 框架 | jQuery 传统页面（无 Vue/React） |
| 答题卡渲染 | `<img>` 标签（相对路径 OSS 图，`image?type=jpeg&p=TOKEN`） |
| 图片获取 | `#pic` 元素 src 拼绝对 URL |
| 分数输入 | 输入框（`input.fenshu`，多小题并列） |
| 提交方式 | `inputkey(']')` 键盘确认流 |

### 答题卡获取

答题卡通过 `<img id="pic">` 渲染，图片 URL 为相对路径（带 `p=TOKEN` 标识）。脚本会：

1. 等待图片 `naturalWidth > 0` 加载完成
2. 自动拼接为绝对 URL 下载
3. 换卷时通过 `p` token 变化检测新试卷

### 满分提取

满分写在分数输入框的 **`fen` 自定义属性**里（如 `fen="12"`），不是 placeholder。脚本从该属性自动提取满分值，填入「分数设置」的评分单元配置。小题标签取 `#btag{i}`（如题号 `24`）。

### 分数填入与提交

填分时写入输入框 `value` 并触发 `input` / `change` / `blur` 事件。

提交采用平台的**键盘确认流** `inputkey(']')`（与按回车提交同路径）：

1. 校验分数非空、数值格式正确、不超过 `fen` 满分
2. 若当前是最后一个小题，触发隐藏提交按钮 `#submit` 完成提交
3. 否则焦点自动移到下一个小题

脚本会先 focus 最后一个分数输入框再调用 `inputkey(']')`，确保平台内部状态正确。

### 多小题评分

支持一道大题拆成多个小题（多个 `input.fenshu` 并列，id 形如 `fenshu0`/`fenshu1`），脚本按顺序逐个填入对应分数。

### 任务标识

URL query 参数（`examsub`/`examtea`/`teaid`/`teaname`）构成任务标识，换题时变化、换学生卷时不变，用于评分方案绑定。满分 `scores` 和图片 token 不参与标识，避免换卷误触发重新绑定。

## 功能支持

| 功能 | 支持状态 |
|------|---------|
| 自动获取答题卡图片 | 支持（相对路径拼绝对 URL） |
| 自动提取满分 | 支持（`fen` 属性解析） |
| 自动填入分数 | 支持（输入框） |
| 自动提交 | 支持（`inputkey(']')` 键盘确认） |
| 等待下一份试卷 | 支持（图片 token 变化检测） |
| 多小题评分 | 支持 |
| 回评模式检测 | 暂不支持 |

## 常见问题

### 脚本没有在页面上激活

1. 确认地址栏路径包含 `/biluo/display.jsp`
2. 确认已进入阅卷界面（页面有答题卡图片和给分板）
3. 刷新页面后检查控制台日志是否有 `[鑫考内网]` 开头的输出

### 提交时提示"分数不能为空"或"分值过大"

这是平台 `inputkey(']')` 的校验提示，说明填分未生效或分数超过满分。请检查：

1. 分数设置里的小题满分是否与页面一致（`fen` 属性值）
2. AI 给出的分数是否超过满分

### 支持附加分吗

支持。附加分输入框（`#fjf`）在页面显示时会被识别为独立评分单元。

### 与公网版鑫考会冲突吗

不会。两者路径不同（`/biluo/display.jsp` vs `/Marking/DisPlay`），脚本分别加载对应适配器。
