# 南昊AI教学提分平台

## 平台简介

南昊AI教学提分平台是一个在线阅卷平台，jQuery 传统页面架构，答题卡图片由平台 `showimage` 接口动态输出（按题裁剪）。

- **阅卷地址**: `https://nhcisc.com/exam/mark/task/taskpaper`

## 技术特点

- **前端框架**: jQuery 传统页面
- **图片渲染**: `<img>` 标签（`showimage` 接口动态输出，按题裁剪）
- **分数输入**: 分数输入框（`input[name="score"]`），placeholder 显示满分（如「满分3」）
- **评分方式**: 键盘输入打分，支持多小题逐题给分
- **特殊功能**: 自动提交选项、试卷标志（优秀试卷/典型错误）

## 使用方法

### 1. 安装脚本

安装 AI 批改助手最新版本。

### 2. 打开阅卷页面

登录南昊AI教学提分平台，进入阅卷页面。页面 URL 应包含 `/exam/mark/task/taskpaper` 路径。

页面结构如下：

- **中间**: 答题卡图片（按题裁剪的答题区域）
- **右侧**: 打分面板（分数输入框 + 提交按钮）

### 3. 使用 AI 批改

1. 脚本会自动检测阅卷页面，显示 AI 批改按钮
2. 点击按钮开始 AI 批改
3. AI 会自动识别答题卡图片、评分
4. 用户确认后，脚本将分数填入输入框并提交

## 平台特殊处理

### 分数格式归一化

平台对分数输入有格式限制（数字 + 单小数点、最多 2 位小数）。脚本填分后自动调用平台的 `clearNoNum` 过滤函数归一化，避免格式不合法导致提交失败。

### 满分自动提取

每个小题的满分显示在输入框占位符中（如「满分3」），脚本自动提取并写入评分配置，无需手动设置。

### 换卷检测

提交后平台直接切换到下一份答卷（答题图与试卷编号同步替换），脚本以此判断下一份已就绪，自动继续批改。

### 方案绑定

任务标识使用页面路径 + 小题 ID + 题号组合，换学生、刷新页面均稳定，绑定评分方案后自动切换，不重复弹出引导。
