# 小乐优阅

入口：`yy.eduer.co`。支持初评键盘给分。

进入对应阅卷任务，核对本题满分、参考答案和评分标准，关闭平台自动提交，先使用试改模式核对结果。助手按平台允许分值填写分数，确认保存后继续下一份。


## 开始批改

1. 安装稳定版 1.21.26.0 或更新版本，登录平台并进入分配给自己的阅卷任务。
2. 等待当前答卷和全部评分项显示完整，核对题号、满分、参考答案与评分标准。
3. 使用平台允许的给分方式，先试改并核对识别作答、得分与给分依据。
4. 确认平台保存成功后继续下一份；保存结果尚未确认时，先在平台核对进度与当前答卷。

切换题目或评分项后需重新核对方案。回评、仲裁及其他批阅模式请使用平台相应入口。
