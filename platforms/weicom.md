# 威科姆（悦卷通）

## 平台简介

威科姆阅卷（悦卷通）是一个在线阅卷平台，使用 jQuery 传统页面架构，答题卡图片托管在阿里云 OSS 上。

- **阅卷地址**: `https://wyna.onlyets.com`

## 技术特点

- **前端框架**: jQuery 传统页面
- **图片渲染**: `<img>` 标签（阿里云 OSS 托管，带裁剪参数和安全 token）
- **分数输入**: 多小题输入框（`.ipt_score`）+ 满分/零分快捷按钮
- **打分模式**: 键盘打分 / 鼠标打分 / 分步骤打分三种模式
- **特殊功能**: 自动提交选项、0 分确认弹窗

## 使用方法

### 1. 安装脚本

安装 AI 批改助手最新版本。

### 2. 打开阅卷页面

登录威科姆阅卷平台，进入阅卷页面。页面 URL 应包含 `/mark/vN/view/` 路径。

页面结构如下：

- **中间**: 答题卡图片（`#imageFullScreen`，OSS 托管）
- **右侧**: 打分面板（各小题分数输入框 + 满分/零分按钮 + 提交按钮）

### 3. 使用 AI 批改

1. 脚本会自动检测阅卷页面，显示 AI 批改按钮
2. 点击按钮开始 AI 批改
3. AI 会自动识别答题卡图片、评分
4. 用户确认后，脚本将各小题分数填入对应输入框

## 打分模式

威科姆平台提供三种打分模式，脚本均已适配：

### 键盘模式

通过键盘输入分数，脚本模拟原生输入事件填入分数输入框。

### 鼠标模式

通过点击分数按钮列表（`.ul_score`）选择分数。

### 分步骤模式

按步骤逐题打分，提交按钮为 `#submitSteps`。

## 平台特殊处理

### 0 分确认弹窗

平台在打 0 分时会弹出确认对话框（`#zeroCheckModal`）。脚本会自动点击确认按钮（`#btn_0_ok`），避免连续批改时被打断。

### 自动提交

支持平台的"自动提交"选项（`#autoSubmit`），填分后平台自动进入下一份试卷。
