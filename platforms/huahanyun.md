# 云阅卷(华翰云)

云阅卷(华翰云)（yj.lcedu.net.cn，吉林华翰云"云阅卷"产品·温州鹿城区部署）是 AI 批改助手在 v1.21.17 中新增支持的阅卷平台。

> 注意：本平台与 [华翰云](/platforms/hanhan)（yunyuejuan.net）同厂不同部署、与 [云阅卷](/platforms/yunyuejuan) 同名不同厂，适配器相互独立。

## 支持的页面

脚本在以下 URL 模式下自动激活：

- `yj.lcedu.net.cn/*` / `*.lcedu.net.cn/*` — 云阅卷(华翰云)批改页面（`#/marking/grading` 路由）

## 功能支持

| 功能 | 支持状态 |
|------|---------|
| 自动获取答题卡图片 | 支持（OBS 题块裁剪图） |
| 自动填入分数 | 支持（单题块单分框，全或无语义） |
| 自动提交 | 支持（给分按钮，失败显式） |
| 等待下一份试卷 | 支持（考生号强信号 + 阻塞式窗口） |
| 分小题评分 | 单题块模式（一个阅卷任务 = 一个题块） |

## 技术特点

平台使用 Vue + Element UI 构建（webpack SPA），批改页为哈希路由 `#/marking/grading?questionId={题块ID}`：

| 特性 | 说明 |
|------|------|
| 框架 | Vue + Element UI（webpack 分包） |
| 答题卡渲染 | `<img>` 标签（OBS 题块裁剪图，考生号在 URL 路径中） |
| 分数输入 | `input#compuinput`（placeholder="请给分"，数字键盘含小数点与满分快捷） |
| 提交按钮 | `button.submitscorebtn`（文字"给分"） |
| 任务标识 | URL `questionId` 参数 |

### 答题卡图片获取

题块裁剪图托管在对象存储（OBS）上，URL 含签名参数。脚本只取**真可见**的题块大图（过滤隐藏残留与小图标），并在换卷判定中要求**旧考生号退出、新考生号出现**（双轨判定），确保不会把新旧两张卷混在一次评分里。

### 分数填入

分数框为 Vue 组件，脚本通过原生 setter + `input`/`change` 事件触发响应式更新，并做全或无校验：缺分、配置错位、NaN/负分/越界一律显式拒绝且不污染原值。

### 换卷检测

答卷图路径含考生号（`.../student/{考生号}/...`），同卷签名抖动不影响判定。等待采用阻塞式窗口（25 秒，与全仓平台一致），换图即刻返回。

## 常见问题

### 页面检测失败

如果打开批改页面后没有出现 AI 批改按钮：

1. 确认当前页面 URL 包含 `#/marking/grading` 且显示了「请给分」输入框
2. 从任务列表点「继续阅卷」进入即可自动弹出配置引导（无需刷新）
3. 按 `F12` 查看控制台日志，检查是否有 `[诊断]` 信息

### 分数填入失败

如果 AI 评分正确但分数没有填入输入框：脚本对缺分/越界/配置错位会**显式拒绝并提示原因**（宁停不带病），请按提示核对方案的评分单元配置（该平台为单题块单分框）。
