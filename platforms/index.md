# 支持平台

<span id="预览版新增平台" class="fp-anchor-alias" aria-hidden="true"></span>

## 预览版平台

[小闲 AI 网上阅卷](/platforms/xiaoxianai)支持普通单题、单份答卷的键盘给分，按本题合法分值与步进校验，确认保存后继续下一份。开始前关闭平台自动提交，并先试改核对。

[园丁邦云阅卷](/platforms/yuandingbang)支持普通单评任务的键盘给分，可按得分点校验满分及给分档位，确认保存后继续下一份。目前通过预览版提供支持，首次使用请先试改。

[丽升阅卷](/platforms/leascent)通过预览版支持铜山高二选择考的英语填空与写作任务，使用正评中的打分板给分，按半分或整数档位填写并确认保存。

## 稳定版平台支持

当前稳定版 **1.21.22.0** 支持 **43 个阅卷平台**。下方目录提供各平台的入口和使用指南。

各平台支持的任务类型、给分方式和提交要求不同，首次使用请先阅读对应指南，再用试改模式核对。

::: info 移动端用户
如果你在手机上浏览，可以点击页面左上角的 **☰ 菜单按钮** 展开侧边目录，在各章节之间切换。
:::
