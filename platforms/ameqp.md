# AMEQP网上评卷

AMEQP网上评卷是 AI 批改助手 v1.21.11.2 新增支持的阅卷平台，常见于内网裸 IP 部署的 ASP.NET WebForms 阅卷系统。

## 支持的页面

- `*://*/AMEQP/Webroot/mar/*` — AMEQP 网上评卷系统（阅卷在弹出窗口 `mar_mark.aspx` 中进行）

::: tip 内网部署说明
AMEQP 平台通常部署在单位内网，访问地址为裸 IP + 端口（如 `http://192.168.x.x/AMEQP/...`），域名不固定。脚本通过**路径特征 + DOM 五特征**联合识别平台，不依赖固定域名。
:::

## 技术特点

AMEQP 基于 ASP.NET WebForms + jQuery + EasyUI 构建：

| 特性 | 说明 |
|------|------|
| 框架 | ASP.NET WebForms + jQuery + EasyUI |
| 答题卡渲染 | `<img>` 标签（整张扫描图） |
| 图片获取 | 题块裁剪图，脚本自动裁切到题块可视区域 |
| 分数输入 | 输入框（`input.mark_tbx`，支持多评分单元） |
| 提交方式 | `OnSubmit(1)` 提交，需同步平台隐藏字段 |

### 答题卡获取

平台页面上的 `img.ansImg` 是**整张答题卡扫描图**，在 `.img_box` 视口里用负偏移裁剪显示当前题块。脚本会自动识别可视区域并裁切，只把**当前题块**发送给 AI，而不是整张答题卡，避免无关内容干扰识别。

::: warning
`tmpImg_*` 开头的图片是透明批注层，不是答题卡内容，脚本会自动跳过。
:::

### 分数填入

分数输入框形如 `input.mark_tbx`（id/name 为 `txt_que_N`，N 为内部序号）。脚本填分时会：

1. 写入输入框 `value` 并触发 `input` / `change` / `blur` 事件（兼容 jQuery EasyUI 组件）
2. 同步平台隐藏字段 `#MarQueSubSco_N`（该题得分）和 `#queVal`（总分显示）

::: danger 必须同步隐藏字段
AMEQP 平台的 `OnSubmit(1)` 提交时会校验隐藏字段判断"是否给分"，**只改输入框 value 不够**，必须同步隐藏字段，否则会误判为"没给分"而跳过当前试卷。脚本已自动处理此逻辑。
:::

### 自动提交

填分并同步隐藏字段后，脚本会延迟一小段时间再触发提交按钮（`#btn_submit`，`onclick="OnSubmit(1)"`），确保平台内部状态已完成同步，避免"没给分"误跳下一份。

### 多评分单元

AMEQP 支持一道大题拆成多个评分单元（多小题），脚本会按 `txt_que_N` 的序号逐个填入对应分数。

## 功能支持

| 功能 | 支持状态 |
|------|---------|

## 常见问题

### 脚本没有在页面上激活

1. 确认地址栏路径包含 `/AMEQP/Webroot/mar/`
2. 确认已进入阅卷弹出窗口（`mar_mark.aspx`）
3. 脚本要求页面同时具备以下 5 个 DOM 特征才会激活（防止内网多系统串台）：
   - `#Mark_main`
   - `img.ansImg`
   - `input.mark_tbx[maxsco]`
   - `input#btn_submit.mark_btn`
   - `#queSco_all`
4. 刷新页面后检查控制台日志是否有 `[AMEQP]` 开头的输出

### 分数填了但提示"没给分"

这是 AMEQP 平台的特殊机制：提交时校验隐藏字段 `#MarQueSubSco_N` 和 `#queVal`，而非输入框本身。请更新到 **v1.21.11.3** 及以上，该版本已修复隐藏字段同步和提交时序问题。

### 绑定试题后仍重复弹出引导界面

v1.21.11.3 已修复此问题（任务标识改用题号而非内部序号）。请更新脚本到最新版本。

### 发送给 AI 的是整张答题卡而不是当前题块

v1.21.11.3 已修复此问题（答题卡取图裁切到题块可视区域）。请更新脚本到最新版本。
