# 海云智评

海云智评是 AI 批改助手 v1.21.12.3 新增支持的阅卷平台（zp.kaow.cn），面向区域学业监测的智能阅卷系统。

## 支持的页面

- `*://zp.kaow.cn/*` — 海云智评教师评卷（`#/grade/teacher/index`，Vue 2 + Element UI 单页应用）

::: tip 单页应用说明
海云智评是 Vue 2 + Element UI 的 SPA，路由使用 hash 模式（`#/grade/teacher/index`）。Tampermonkey 的 `@match` 不匹配 hash 部分，因此一条域名级规则即可覆盖所有页面；脚本加载后通过 hash 判断是否进入阅卷界面。
:::

## 技术特点

海云智评基于 Vue 2 + Element UI 构建：

| 特性 | 说明 |
|------|------|
| 框架 | Vue 2 + Element UI |
| 答题卡渲染 | `<img>` 标签（阿里云 OSS 裁剪图） |
| 图片获取 | `.img_contain img`，保留 OSS 裁剪参数原样 URL |
| 分数输入 | 输入框（`input.inputs`，多小题并列） |
| 提交方式 | `#btnSubmit` + 二次确认弹窗自动确认 |

### 答题卡获取

答题卡通过 `<img id="leftimg">` 渲染，图片托管在阿里云 OSS，URL 中带有 `x-oss-process=image/rotate,.../crop,...` 裁剪参数。脚本会：

1. 等待图片 `naturalWidth > 0` 加载完成
2. 原样保留 OSS 裁剪参数 URL 下载（只截取当前题块区域）
3. 支持多张答题卡（多页扫描时多个 `.img_contain` 各含一张）

::: tip 换卷检测
提交后平台加载下一份答卷时，脚本通过图片 URL path 变化或输入框清空来判定新试卷就绪，最多等待 10 秒。
:::

### 分数填入与满分提取

给分面板中每道小题是一个 `.sub-item`，包含小题标题（`.sub-name-caption`，如 `1.4`）、满分（`.sub-score`，如 `(19)`）和分数输入框（`input.inputs`）。

脚本会从 `.sub-score` 文本中提取满分值（兼容小数满分如 `(2.5)`），自动填入「分数设置」的评分单元配置，减少手动填写。

填分时写入输入框 `value` 并触发 `input` / `change` / `blur` 事件（兼容 Vue 双向绑定）。

### 提交二次确认

点击「提交分数」后，平台会弹出 **el-dialog 二次确认对话框**（显示本次得分），需要再点一次「提交」。脚本会：

1. 点击 `#btnSubmit`（提交分数）
2. 轮询等待确认弹窗出现（最多 3 秒）
3. 自动点击确认按钮 `#submitShortcutMarkPaper`

无需人工干预，无人值守模式下可连续批改。

### 多小题评分

支持一道大题拆成多个小题（多个 `.sub-item` 并列），脚本按顺序逐个填入对应分数。页面右上角「当前科目 / 题组」和小题标签共同构成任务标识，换题组时自动重新绑定评分方案。

## 功能支持

| 功能 | 支持状态 |
|------|---------|
| 自动获取答题卡图片 | 支持（OSS 裁剪图，支持多页） |
| 自动提取满分 | 支持（`.sub-score` 文本解析，兼容小数） |
| 自动填入分数 | 支持（输入框） |
| 自动提交 | 支持（含二次确认弹窗自动处理） |
| 等待下一份试卷 | 支持 |
| 多小题评分 | 支持 |
| 回评模式检测 | 暂不支持 |

## 常见问题

### 脚本没有在页面上激活

1. 确认地址栏是 `zp.kaow.cn/#/grade/teacher/index`
2. 确认已进入阅卷界面（页面有答题卡图片和给分面板）
3. 刷新页面后检查控制台日志是否有 `[海云智评]` 开头的输出

### 满分没有自动检测出来

1. 确认给分面板已加载（小题标题旁显示如 `(19)` 的满分）
2. 点击配置面板的「检测页面输入框」重新检测
3. 若满分显示为空，说明页面结构可能有变化，请反馈页面 DOM

### 提交后卡在确认弹窗

脚本会自动点击确认按钮（`#submitShortcutMarkPaper`），最多等待 3 秒。若超时未自动确认，请检查是否弹出了非标准对话框（如问题卷类型选择），此时需手动处理后继续。

### 支持回评模式吗

暂不支持回评模式识别，回评界面下脚本不会自动隐藏批改按钮，请注意区分。
