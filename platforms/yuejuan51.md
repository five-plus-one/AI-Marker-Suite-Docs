# 恒佳考试服务云平台

## 平台简介

恒佳考试服务云平台（南昌恒佳科技）与[睿芽考试服务云平台](/platforms/ruiya)是同一厂商同一套 OnlyETS CampusManage/MarkClient 代码，仅租户品牌不同。适配器经实测两平台批改页选择器逐字一致，按多租户方式一并支持。

- **阅卷地址**：`http://x.yuejuan51.com`（仅 http 明文部署，https 证书无效）
- **批改页面**：`/mark/v6/view/<32位GUID>`
- **UI 显示**：脚本面板按域名自动显示「恒佳阅卷」

## 技术特点

与[睿芽](/platforms/ruiya)完全一致：

- **答题卡**：阿里云 OSS 题块裁剪图（带 `data-stu` 学生标识）
- **多小题评分**：`input.ipt_score`，满分取「<= N」提示
- **提交**：「提交(Enter)」对接平台 `Mark.submitKeyboard` 语义
- **翻卷检测**：密号 + `data-stu` + 图片路径三重强信号
- **回评识别**：`#reviewPanel` 面板可见性判定
- **弹窗处理**：0 分确认自动确认、「阅卷小提示」自动关闭

## 使用方法

同[睿芽](/platforms/ruiya)：登录恒佳 → 任务列表「开始阅卷」→ 批改页 → 点击 **AI 批改** 开始批改。

## 注意事项

- 仅支持**键盘打分模式**（分步模式不支持；鼠标模式填分时自动切回键盘）
- 登录页无滑块验证，密码由页面脚本自动加密提交，无需额外操作
- 与睿芽共用同一适配器，功能更新两平台同步生效

## 常见问题

**Q: 为什么脚本面板显示「恒佳阅卷」而不是「睿芽阅卷」？**

适配器按域名自动区分租户品牌（`yuejuan51.com` 显示恒佳），功能完全一致。

**Q: 可以同时在恒佳和睿芽使用吗？**

可以。同一脚本覆盖两个平台，方案绑定按题块分别生效。
