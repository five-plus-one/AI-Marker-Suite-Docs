# 小帆智能阅卷

## 平台简介

小帆智能阅卷（安徽小帆智能科技）是多租户在线阅卷平台，教师从统一入口登录后按租户跳转到子域（如 `xj.xfkj.cc`）。

- **登录入口**：`https://www.xfkj.cc/manage/login`（含滑块验证码，手动完成即可）
- **批改页面**：`/pages/exam/yuejuan/review.aspx?id=任务id&isai=0`
- **技术栈**：layui + jQuery + ASP.NET WebForms 多页应用

## 技术特点

- **答题卡**：`.review_body>ul>li>img`，阿里云 OSS 题块裁剪图（多页多张，带签名参数）
- **多小题评分**：`.quickmenu>.qlist>li` 每小题一个 `input.score-input`，placeholder「满分N分」自动提取满分
- **提交**：「提交」按钮 → 平台校验全部小题后提交，成功后自动翻下一份
- **翻卷检测**：答题卡图片**路径**变化（OSS 签名 query 每次刷新会变，只比路径）
- **回评识别**：「结束回评」按钮可见即回评模式；「上一张/下一张」切换历史卷
- **任务标识**：批改页 URL 换卷不变，方案按题块复用

## 使用方法

### 1. 安装脚本

安装 AI 批改助手最新版。

### 2. 进入批改页面

登录小帆平台 → 「阅卷任务」→ 考试详情 → 题块的「初 评 / 终 评」入口进入批改页（地址含 `review.aspx`）。

### 3. 使用 AI 批改

1. 脚本自动检测批改页面，右下角显示 **AI 批改** 按钮
2. 首次使用按引导配置 API 密钥与方案（可勾选绑定当前题块）
3. 点击开始批改，AI 识别答题卡并评分，确认后自动填分提交并翻到下一份

## 注意事项

- 双评任务区分**初评/终评**入口；回评修改分数请走「回 评」进入回评模式
- 平台「自动提交」勾选只由快捷打分按钮触发；适配器直接填输入框再点提交，不绕过确认环节
- 0 分卷的确认弹窗由适配器自动处理；「阅卷小提示」弹窗可点「不再提示」关闭
- 平台的全局 Enter / 右键提交仅当「启用鼠标右键提交」勾选时生效（默认关闭）

## 常见问题

**Q: 批改页没有出现 AI 批改按钮？**

确认当前地址是 `review.aspx` 批改页（而非阅卷任务列表/考试详情页）；题目与图片为异步渲染，等待页面加载完成后重新打开。

**Q: 提交后一直等待下一份？**

平台加载较慢时会等待最多 25 秒；若任务已批完或试卷尚未分发完成，会自动暂停并提示。
