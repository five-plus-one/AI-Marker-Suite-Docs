# 云阅卷(开州)

## 平台简介

云阅卷(开州) 是基于 Vue 3 + Element Plus 的单页应用（SPA）阅卷平台。

- **阅卷地址**: `https://yyj.kzedu.cn`
- **评阅页面**: hash 路由 `/marking/grading?questionId=..`

## 技术特点

- **前端框架**: Vue 3 + Element Plus（SPA）
- **图片渲染**: `<img>`（`.svg-container` 内，带 SVG 批注图层；图片为 S3 预签名 URL）
- **分数输入**: 只读分数框（`.redbiginput input`）+ 点击式评分按钮 `button.scoreitem`（0..满分）
- **分数提交**: 点击「给分」（`button.submitscorebtn`）
- **满分/零分**: `.givescorebox` 内的成功/危险色按钮
- **翻卷检测**: URL 仅含题号（学生切换 URL 不变），**靠图片 src 路径变化**判定翻卷

## 使用方法

### 1. 安装脚本

安装 AI 批改助手最新版本。

### 2. 打开评阅页面

登录云阅卷(开州)平台，进入批改页面（hash 路由含 `/marking/grading`）。页面结构：

- **中央**: 答题卡图片区（`.svg-container`，含 SVG 批注层）
- **右侧**: 评分面板，含分数按钮（0..满分）、只读分数框、「给分」提交按钮

### 3. 使用 AI 批改

1. 脚本自动检测批改页面，右下角显示 **AI 批改** 按钮
2. 点击开始批改，AI 识别答题卡并评分
3. 确认后脚本填入分数并提交，自动翻到下一份

## 注意事项

- **「自动给分」勾选状态决定提交方式**，脚本会自适应：
  - **勾选时**：点击评分按钮会立即提交并自动翻卷（无确认弹窗）。此时脚本只点 scoreitem 给分，**不再点「给分」**——否则会给下一份误打分
  - **未勾选时**：点击评分按钮只填分，需再点「给分」才提交
- 脚本**从不主动点击评分按钮去触发提交**，点击动作统一推迟到提交阶段，避免跳过你的确认环节
- 页面元素 id（`el-id-XXXX-XX`）每次刷新都会变，脚本只依赖类名/属性定位，不受影响

## 常见问题

**Q: 提交后翻卷检测不准？**
A: 该平台 URL 不随学生变化，脚本靠图片 src 路径变化判定翻卷。若图片走缓存导致路径不变，可能误判——此时会在填分前的答卷一致性校验处拦截并提示人工核对。

**Q: 「自动给分」勾选时分数被重复提交？**
A: 这是平台的即时提交机制。脚本已按勾选状态分支处理；若仍出现，请取消勾选「自动给分」，改用「给分」手动确认。

**Q: 分数框是只读的，AI 能填进去吗？**
A: 可以。脚本通过原生 setter 赋值并派发必要事件，已实测可被平台接受。
