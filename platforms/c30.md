# C30教育云

C30教育云（zy.iclass30.com）是 AI 批改助手 v1.21.11 新增支持的阅卷平台。

## 支持的页面

- `zy.iclass30.com/*` — C30教育云阅卷系统（批改页路由包含 `/webCorrect`）

## 技术特点

C30教育云基于 Vue + Element UI 构建，答题卡使用 Canvas 渲染：

| 特性 | 说明 |
|------|------|
| 框架 | Vue SPA + Element UI |
| 答题卡渲染 | Canvas |
| 图片获取 | Canvas 直接导出 |
| 分数输入 | 输入框 + 快捷分数按钮 |
| 提交方式 | 平台自动提交推进 |

### 答题卡获取

答题卡通过 Canvas 渲染，脚本直接调用 Canvas 的导出接口获取图片数据，无需拦截网络请求。同时脚本会拦截 `getCorrectStuList` 接口响应，用于感知学生列表变化、判断是否切换到下一份答卷。

### 分数填入

脚本优先使用页面上的**快捷分数按钮**（点击即设置对应分数），没有匹配的按钮时回退到**输入框**直接填入。

### 自动提交

C30教育云没有显式的提交按钮，平台在分数设置完成后自动保存并推进到下一位学生。脚本会自动处理过程中出现的确认弹窗。

### 满分自动检测

进入批改页面后，脚本会自动从分数输入框的提示文字中读取满分值并写入当前预设方案（最多重试 3 次）。如果你已手动配置过满分，则不会覆盖。

## 功能支持

| 功能 | 支持状态 |
|------|---------|
| 自动获取答题卡图片 | 支持（Canvas 导出） |
| 自动填入分数 | 支持（快捷按钮 / 输入框） |
| 自动提交 | 支持（平台自动推进） |
| 等待下一份试卷 | 支持 |
| 分小题评分 | 不支持（平台为单一总分输入框） |
| 回评模式检测 | 支持 |

## 常见问题

### 脚本没有在页面上激活

1. 确认地址栏域名是 `zy.iclass30.com`
2. 确认已进入批改页面（页面路由包含 `/webCorrect`）
3. 刷新页面后检查控制台日志是否有 `[C30]` 开头的输出

### 分数没有填入

1. 确认页面上显示了分数输入框或快捷分数按钮
2. 检查是否已正确配置满分（脚本会自动检测，也可在设置面板手动填写）
3. 更新脚本到最新版本（C30教育云需要 v1.21.11 及以上）
