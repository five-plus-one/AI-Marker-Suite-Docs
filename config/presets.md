# 预设方案管理

为不同题目分别保存场景方案。打开已绑定的试题时，助手会选中对应的方案。

## 什么是预设方案？

方案保存题目内容、参考答案、评卷标准、分数设置、运行模式、所选工作流和本方案的自动化选项。供应商和模型在「AI」中管理，由工作流选用。同一个工作流可用于多个方案。

## 基本操作

### 创建新方案

1. 打开「批改配置 → 方案 → 场景方案」，点击「新建」。
2. 输入方案名称，例如「语文作文」或「数学大题」。
3. 在「批改」中填写批改资料，核对题号、满分、步长并选择运行模式。在「AI」中选择工作流。
4. 在当前试题上复用此方案时，可勾选「绑定至当前试题」。点击「保存并启用」。

### 切换方案

在「方案 → 场景方案」的下拉列表中选择。核对页面显示的资料、工作流和运行模式，再点「保存并启用」。

### 删除方案

在「场景方案」选中要删除的方案，点「删除」并确认。

::: warning 注意
删除方案后无法恢复。「默认配置」保留在列表中。
:::

### 导出 / 导入单个方案

换设备或与同事共享配置时，可以把**单个方案**（含题目内容、参考答案、评卷标准及插入的图片）导出为 JSON 文件，再导入合并。

- **导出此方案**：导出当前选中方案，文件形如 `ai-marker-preset_方案名_日期.json`
- **导入方案**：导入单个方案文件。若同名方案已存在会提示覆盖确认；选择「取消」则跳过导入，不影响现有方案

快捷入口有两处，方便在配置过程中随手导出：

1. **方案**页 —「场景方案」栏（新建/删除旁）
2. **批改**页 —「方案导入导出」区（配置完详细项直接导出）

「数据」页的**导出配置/导入配置**是全量备份（含所有方案、供应商、工作流），与单方案导入导出不同。

::: tip 含图片方案
题目内容、参考答案、评卷标准中插入的图片会一并打包。换设备后，请检查对应的工作流和供应商是否已配置。
:::

## URL 绑定（自动切换）

把方案绑定到当前试题后，再次打开这道题时，助手会自动选择相应的方案。

### 设置绑定

1. 打开目标题目的阅卷页面。
2. 在「方案 → 场景方案」选择或创建方案。
3. 勾选「绑定至当前试题」，再点击「保存并启用」。

### 工作原理

助手识别到试题切换时，会优先选择该题绑定的方案。尚未绑定时使用「默认配置」。如果开启了「切换题目时自动显示配置引导」，可按提示核对当前方案。

### 解绑

在已绑定的试题上选中对应方案，取消勾选「绑定至当前试题」，再点击「保存并启用」。

## 使用场景示例

### 场景一：语文老师批改作文

创建两个方案：

| 方案 | 题目内容 | 评分标准 |
|------|---------|---------|
| 大作文 | 800字议论文 | 立意(10)+内容(10)+结构(10)+语言(10) |
| 微写作 | 200字应用文 | 内容(5)+格式(3)+语言(2) |

把两份方案分别绑定到对应试题。

### 场景二：数学老师批改解答题

| 方案 | 题目 | 评分标准 |
|------|------|---------|
| 函数题 | 求函数单调性 | 列式(3)+求导(3)+讨论(4)+结论(2) |
| 几何题 | 证明线面平行 | 作辅助线(2)+证明(6)+结论(2) |

### 场景三：使用不同 AI 服务商

| 方案 | 工作流使用的供应商与模型 | 适用场景 |
|------|----------|---------|
| 作文 | 5+1 AI (aimarker-fast) | 作文需要较强的中文理解能力 |
| 数学 | 自定义工作流，选择供应商提供的视觉模型 | 先试改，核对公式识别和分步给分 |

## 配置导入/导出

脚本支持将所有配置导出为 JSON 文件，方便备份和迁移。

### 导出配置

1. 打开「批改配置 → 数据 → 配置管理」。
2. 点击「导出配置」，下载包含方案、供应商和工作流的 JSON 文件。

### 导入配置

1. 打开「数据 → 配置管理」，点击「导入配置」。
2. 选择备份 JSON 文件，核对提示后确认。全量导入会覆盖当前配置。
3. 换浏览器后，按需重新连接五加一账号。

::: tip 备份建议
在更换浏览器或电脑前，建议先导出配置文件。配置和单方案导出文件可能包含明文 API 密钥与插入图片，请保存到可信位置。分享前先删除密钥和学生信息。
:::

## 多个页面同时编辑

在不同阅卷页面分别修改方案、供应商或工作流时，保存会合并其他页面已保存的修改。同一内容同时被改动时，助手保留当前编辑并提示核对；请先导出本次修改，再检查其他页面保存的内容后重试。

首次使用或升级时若提示保存失败，请按页面提示重新保存，并在刷新前备份尚未保存的设置。
