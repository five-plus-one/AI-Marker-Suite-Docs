# 评分规则

评分规则随当前方案保存。开始批改前，请核对批改资料与当前题号、满分和给分步长。

## 三个关键字段

打开「批改配置 → 批改 → 批改上下文」，点击字段旁的「编辑」。题目内容按需填写，参考答案和评卷标准必填。完成编辑后点击「确认」，再点击「保存并启用」。

### 题目内容

试卷上的**原始题目**，告诉 AI 这道题在问什么。

**示例：**
```
阅读下面的材料，根据要求写作。
"路虽远，行则将至；事虽难，做则必成。"
请以"坚持"为话题，写一篇不少于800字的议论文。
```

<span id="标准答案" class="fp-anchor-alias" aria-hidden="true"></span>

### 参考答案

**参考答案**或**评分样例**，告诉 AI 什么样的答案是好的。

**示例：**
```
优秀的议论文应当：
1. 有明确的中心论点（坚持的重要性）
2. 使用至少2个事实论据和1个道理论据
3. 论证结构清晰：引论-本论-结论
4. 语言流畅，无明显语病
5. 字数达到800字以上
```

<span id="评分标准" class="fp-anchor-alias" aria-hidden="true"></span>

### 评卷标准

**给分/扣分细则**，告诉 AI 如何分配分数。这是最重要的字段。

**示例：**
```
满分40分，分项评分：
- 立意(10分)：观点明确、切合题意得8-10分；基本切题得5-7分；偏离题意得0-4分
- 内容(10分)：论据充实、论证有力得8-10分；论据单薄得5-7分；内容空洞得0-4分
- 结构(10分)：结构完整、层次清晰得8-10分；结构基本完整得5-7分；结构混乱得0-4分
- 语言(10分)：语言流畅、有文采得8-10分；语言通顺得5-7分；语病较多得0-4分
- 每少50字扣1分，最多扣3分
```

## 参考图片与文字

题目、参考答案和评卷标准都支持文字、公式和图片。把图片粘贴或拖到编辑区，也可以点击工具栏的「插入图片」。

- **裁切图片**可选取题干、答案或评分点所在区域再插入。
- **AI 识别**会把图片中的文字和公式转成可编辑内容。对照原图检查题号、公式和给分点后，点击「确认插入」。
- **直接插入**可保留原图，适用于需要保留的图形、表格或版面。

![粘贴参考图片后，可选择裁切图片、AI 识别或直接插入](https://img.five-plus-one.com/i/2026/11/22/1536a7a8e98be3ea.png)

批改使用正文中仍有引用的参考配图。若识别成文字后仍需原图，请保留图片引用。试改时对照学生原卷检查作答是否识别准确。参考图与作答容易混淆时，可按方案开启[配图作答核对](/modes/unattended#答卷核对与待复核)。公式的写法见[公式语法指南](./formula)。

## 编写技巧

### 具体化评分标准

| 不好的写法 | 好的写法 |
|-----------|---------|
| "根据质量给分" | "观点明确(5分)，论据充分(5分)，结构完整(5分)，语言流畅(5分)" |
| "答案正确得满分" | "列式正确得3分，计算过程正确得4分，最终答案正确得3分" |
| "酌情给分" | "指出一种修辞手法得2分，分析效果得1分，满分6分" |

### 提供分数梯度

为每个评分维度提供不同分数档的描述，帮助 AI 更准确地定位分数：

```
内容评分(20分)：
- 18-20分：内容丰富，紧扣主题，有独到见解
- 14-17分：内容较充实，基本切合题意
- 10-13分：内容一般，部分偏离题意
- 6-9分：内容单薄，偏离题意较多
- 0-5分：内容空洞或完全偏题
```

### 包含扣分项

明确列出扣分规则，避免 AI 遗漏：

```
扣分项：
- 错别字：每个扣0.5分，最多扣3分
- 标点错误：每3处扣0.5分，最多扣2分
- 字数不足：每少50字扣1分
- 未写标题：扣2分
```

## 不同题型的配置建议

### 作文类

- 重点描述评分维度（立意、内容、结构、语言）
- 提供不同分数档的详细描述
- 列出扣分项（错别字、字数不足等）

### 解答题

- 明确每个步骤的分值
- 包含常见的解题方法
- 说明计算过程和最终答案的分值分配

### 论述题

- 列出需要涵盖的要点
- 说明每个要点的分值
- 描述不同深度的答案对应的分数

### 翻译题

- 提供标准译文
- 列出关键词的翻译分值
- 说明语法正确性和流畅性的权重

## 纠错优化

如果 AI 打分不准确，可以使用**分数纠错**功能：

1. 在试改或普通模式的提交窗口点「分数有误」，输入教师给分和给分理由。
2. 只调整本卷时点「仅修改分数」。要优化方案时，使用「提示词优化」，核对并编辑助手建议的参考答案和评卷标准。
3. 点击「应用修改并确认得分」保存修改，再用其他答卷验证评分是否符合预期。

提示词优化需要本轮的识别答案。详见[分数纠错](../advanced/correction)。

## 勤勉加分

题目允许酌情加分时，可对作答认真但得分点较少的答卷设置勤勉加分。

### 启用与配置

1. 打开「批改 → 勤勉加分」，勾选「启用勤勉加分」。
2. 设置「最大勤勉分」和「衰减强度」。原始得分越高，可加的分通常越少。
3. 可在「自定义评估标准」中说明如何判断作答认真程度，例如要求写出一定数量的有效步骤。留空时使用默认标准。

### 注意事项

加分后的结果仍受题目满分和给分步长约束。勤勉加分默认关闭，开启后按当前方案使用。
