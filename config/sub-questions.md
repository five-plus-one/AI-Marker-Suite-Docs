# 分小题配置

当阅卷平台为一道大题提供多个评分框时，脚本可以分别给出各小题的分数、评语，并汇总总分。评分项的数量和顺序应与平台一致。

## 适用场景

- **作文**：分内容、语言、结构、书写等维度分别评分
- **解答题**：分多个小问分别评分（如第(1)问、第(2)问）
- **论述题**：分论点、论据、结论等维度分别评分
- **翻译题**：分关键词翻译、语法正确性、流畅度分别评分

## 自动检测

进入阅卷任务后，在「批改 → 分数设置」点击「检测页面输入框」：

1. 脚本识别当前页面的评分框，生成评分项列表。
2. 按页面顺序核对各项题号、标签和小题满分。
3. 设置与平台允许分值一致的给分步长，再保存方案。

::: tip 预览版评分项配置
从 1.21.22.2 预览版起，评分项根据页面检测结果生成。如果没有正确检测，请联系作者适配，并提供当前评分栏的截图。
:::

## 核对评分项

每项需要核对以下内容：

- **小题**：与页面对应的题号或评分项名称。
- **小题分**：该项满分，各项相加应与本题总分一致。
- **步长**：允许给分的最小间隔。

| 步长 | 含义 | 适用场景 |
|---|---|---|
| `1`（默认） | 整数分（0、1、2…） | 大多数题目 |
| `0.5` | 半分（0、0.5、1、1.5…） | 按 0.5 计分的题目 |
| `0.25` | 四分之一分（0、0.25、0.5…） | 允许精细给分的题目 |
| `1.5` / `2` / `2.5` | 自定义给分间隔 | 按平台允许的档位给分 |

作文的内容、语言、结构等维度可以写入评分标准；实际填分的评分项对应平台提供的输入框。

::: tip 0.5 / 0.25 步长
步长可自由填写正数，例如 0.5、0.25、1.5、2 或 2.5。AI 给分、双评合并和纠错使用对应梯度；满分不是步长整数倍时仍可给满分。请确保与平台实际允许的分值一致。
:::

## 评分提示词

启用分小题后，脚本会自动调整发送给 AI 的提示词，要求 AI 分别给出每个小题的分数和评语。

AI 返回的格式示例：

```
【内容】15/20
论据充实，紧扣主题，但缺少反面论证。

【语言】17/20
语言流畅，用词准确，有少量语病。

【结构】18/20
结构完整，层次清晰，首尾呼应。

总分：50/60
```

## 分小题纠错

在分小题模式下，纠错功能支持对每个小题独立修正：

1. AI 打分后弹出提交确认对话框
2. 显示每个小题的 AI 得分
3. 如果某个小题打分不准，可以只修改该小题的分数
4. 总分自动计算（各小题之和），也可手动覆盖

## 与单题模式的切换

- 当页面只检测到 1 个分数输入框时，自动使用单题模式
- 当页面检测到 2 个及以上分数输入框时，自动启用分小题模式

## 配置示例

### 作文分项评分

```yaml
小题列表:
  - 标签: "内容"
    满分: 20
  - 标签: "语言"
    满分: 20
  - 标签: "结构"
    满分: 10
  - 标签: "书写"
    满分: 5

评分标准: |
  内容(20分)：
  - 18-20分：切合题意，内容充实，有独到见解
  - 14-17分：基本切合题意，内容较充实
  - 10-13分：部分偏离题意，内容一般
  - 0-9分：严重偏题或内容空洞

  语言(20分)：
  - 18-20分：语言流畅，有文采
  - 14-17分：语言通顺，偶有佳句
  - 10-13分：语言基本通顺
  - 0-9分：语病较多，表达不清

  结构(10分)：
  - 9-10分：结构完整，层次分明
  - 6-8分：结构基本完整
  - 0-5分：结构混乱

  书写(5分)：
  - 5分：字迹工整，卷面整洁
  - 3-4分：字迹较清楚
  - 0-2分：字迹潦草，难以辨认
```

### 数学解答题分问评分

```yaml
小题列表:
  - 标签: "第(1)问"
    满分: 5
  - 标签: "第(2)问"
    满分: 7
  - 标签: "第(3)问"
    满分: 8

评分标准: |
  第(1)问(5分)：
  列出正确的等式或方程得3分，解出正确答案得2分。

  第(2)问(7分)：
  正确建立坐标系得2分，求出正确向量得3分，最终结果正确得2分。

  第(3)问(8分)：
  正确分类讨论得3分，每种情况推导正确得2分，最终结论完整得1分。
```
