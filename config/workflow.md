# 批改工作流

在 **批改配置 → AI → 批改工作流** 选择「当前工作流」，再点击「保存并启用」。工作流决定模型和评分方式。提交时机由「批改 → 运行模式」决定，任一工作流都可配合试改模式逐份确认。

::: info 移动端用户
如果你在手机上浏览，可以左右滑动查看表格。
:::

## 内置工作流

首次配置时，在选择运行模式后可选内置工作流。引导里的「高精模式」在设置中叫「普通批改」，「双评模式（推荐）」对应「双评模式（高精度）」。

| 工作流 | 主模型 | 适合场景 |
|--------|--------|---------|
| **快速批改（推荐）** | aimarker-fast（不思考） | 速度快、性价比高，适合大多数题型 |
| **普通批改** | aimarker-pro（默认深度） | 精度更高，适合复杂题型 |
| **双评模式（高精度）** | 主、副模型均为 aimarker-fast（不思考），仲裁使用 aimarker-pro | 独立评分，分差超过阈值时仲裁 |

## 模型选择

「5plus1官方」提供 **aimarker-fast**、**aimarker-pro** 与 **DeepSeek Flash**（`deepseek-flash`）。配置好账号或密钥后，在工作流编辑器中选择供应商和模型。

自定义供应商的模型列表为空时，先在目标供应商中添加模型，再回到工作流选择。阅卷服务必须能处理图片输入。

## 自定义工作流

你可以创建自己的工作流，自由组合：

- **供应商**：5plus1 官方、火山引擎、OpenAI 兼容等
- **模型**：每个供应商下的可用模型
- **思考参数**可留空，或填写模型支持的值
- **限制单次回答长度**：控制单次 AI 回复的输出额度上限

### 创建步骤

1. 在「AI → 批改工作流」中点「新建」，输入工作流名称。
2. 在编辑窗口里选择主模型的供应商和模型，按需填写思考参数并设置回答长度。
3. 点击「保存」。回到 AI 页后，将该工作流选为「当前工作流」，再点击「保存并启用」。
4. 用「试改模式」核对几份答卷的作答识别和给分，再决定是否连续批改。

## 限制单次回答长度

在工作流编辑器中，可用「限制单次回答长度」控制 AI 回复的输出额度。

**为什么需要它**：部分深度思考模型会把输出额度大量消耗在思考链上，导致正式回答被截断、正文为空，批改时解析不到分数。

**使用方法**：

1. 在工作流编辑窗口中勾选「限制单次回答长度」
2. 设置「回答长度上限」（默认 2048，单位 token）
3. 保存工作流

**行为说明**：

- 默认开启限制，上限为 2048 token。取消勾选后，由模型服务决定回答长度。
- 设置了上限且回答被截断时，若本轮还有重试次数，助手会尝试一次由服务决定长度的请求。

::: tip 建议
若发现 AI 频繁返回被截断的不完整结果，可勾选此选项并适当调高上限值。
:::

## 双评模式

双评模式使用两个 AI 模型独立评分：

1. **主模型**和**副模型**同时对同一份试卷评分
2. 总分分差在阈值内时，按所选合并策略给分。默认阈值是 2 分，默认取平均后四舍五入。
3. 总分分差超过阈值时，由**仲裁模型**结合两个评分结果重新判断。启用「分小问作答核对」时，任一小问的分差超过阈值也会触发仲裁。

### 配置双评

1. 在工作流编辑窗口中勾选「启用双评模式」
2. 选择副模型（供应商 + 模型 + 思考深度）
3. 选择仲裁模型（建议使用更高精度的模型）
4. 设置分差阈值（默认 2 分），并选择双评合并策略

### 双评合并策略

分差在阈值内时，可选择以下策略；超过阈值则进入仲裁：

| 策略 | 给分方式 |
|---|---|
| 平均后四舍五入 | 两个分数取平均，再按给分步长取整（默认） |
| 向下取整到梯度 | 两个分数取平均，再向下取到允许的分值 |
| 向上取整到梯度 | 两个分数取平均，再向上取到允许的分值 |
| 取低分 | 选择较低分；需对齐步长时向下取整 |
| 取高分 | 选择较高分；需对齐步长时向上取整 |

结果受小题满分约束，分小题评分时总分按各小题合并结果相加。阈值设为 **0** 时，两模型给分完全一致即可形成共识，有分差时进入仲裁。

### 双评结果

批改完成后，提交对话框会显示双评详情：
- 主模型和副模型的评分。详细输出可查看评分依据
- 分差
- 判定结果（共识 / 三评仲裁）

## 思考链深度

部分模型允许在工作流的「思考参数」中设置推理深度。常见选项如下，以模型支持的值为准。

| 深度 | 说明 | 适用场景 |
|------|------|---------|
| 不设置 | 模型默认行为 | 大多数场景 |
| minimal | 不思考，直接输出 | 速度优先 |
| low | 轻度思考 | 简单题型 |
| medium | 中度思考 | 复杂题型 |
| high | 深度思考 | 需要详细推理的题目 |

留空时使用模型默认设置。Ling 模型可用 `disabled` 关闭长思考。
