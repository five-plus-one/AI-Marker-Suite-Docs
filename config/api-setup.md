# AI 接口配置

打开阅卷页面右下角的「批改配置」，在 **AI → 供应商与模型** 中连接服务，再到 **AI → 批改工作流** 选择实际用于评分的模型。批改会把答题卡图片发给所选服务，模型须支持图片输入。

<span id="推荐-5-1-ai" class="fp-anchor-alias" aria-hidden="true"></span>

## 连接五加一官方服务

选择供应商「5plus1官方」。已连接五加一账号时，助手优先使用账号授权。已有官方 API 密钥也可以直接填写。

<span id="获取步骤" class="fp-anchor-alias" aria-hidden="true"></span>

### 使用五加一账号

1. 在首次引导的「连接批改服务」，或在设置的「供应商与模型」中，点击「登录五加一账号」。
2. 在新标签页完成登录或注册，并确认授权，然后回到阅卷页。
3. 在首次引导中，助手会测试批改线路。看到「批改服务已就绪」后，点击「配置批改方案」。从设置连接时，可在看到「已连接」后点击「测试线路」。

授权过期时重新连接。要在这台设备上改用另一账号或手动密钥，可先点击「解除连接」。

### 使用已有 API 密钥

1. 已有官方密钥可直接使用。需要新建时，在设置中展开「手动配置 API 密钥」，点击「获取 API 密钥」。[五加一密钥管理](https://platform.ai.five-plus-one.com/sign-in?provider=5plus1-account&redirect=%2Fkeys)
2. 首次引导中选择「或使用已有 API 密钥」，填入密钥并点击「验证并继续」。若从设置配置，在「5plus1官方」下填入密钥，可点击「测试线路」验证，再点击「保存并启用」。

<span id="官方端点" class="fp-anchor-alias" aria-hidden="true"></span>

### 连接与切换端点

在 **AI → 供应商与模型 → 批改线路** 中点「测试线路」。展开「线路设置」可保持「自动选择」，也可指定一条官方线路。自动选择使用服务当前指定的默认线路，列表以页面为准。下图展示自动选择、主端点、香港端点、绍兴端点和上海备用端点。

![五加一官方批改线路设置，展开后可测试或切换线路](https://img.five-plus-one.com/i/2026/11/22/f9f2fccf72ad667f.png)

遇到线路连接故障时，助手可在测试或批改重试时尝试备用线路。若设置页的测试提示另一条线路可用，可点击「改用…」将它设为当前线路。官方线路共用批改账户、密钥和余额，切换后可以继续使用同一工作流。暂时取不到最新线路列表时，助手仍可使用已知线路。

### 余额与充值

脚本可免费使用。AI 模型调用按所选服务和模型计费，实际消耗与题目、图片和回答长度有关。双评、仲裁、额外识别和重试可能增加调用。请求超时后服务仍可能继续处理，重试可能产生额外费用。可在「自动化 → 自动重试」关闭「超时时也重试」。

已连接五加一账号时，点击同一设置页的「余额与充值」。使用官方手动密钥时，登录该密钥所属账号查看额度和充值。价格、可用额度和充值状态以服务控制台为准。收到余额不足提示时，待充值到账后再测试或继续批改。[五加一余额与充值](https://platform.ai.five-plus-one.com/sign-in?provider=5plus1-account&redirect=%2Fwallet)

## 其他兼容服务

可以使用支持 OpenAI 兼容聊天补全接口和图片输入的服务。在服务商控制台取得**完整请求地址、模型 ID 和 API 密钥**。确认所选模型支持发送图片，并确认账号有调用该模型的权限。

### 火山引擎（豆包）

在 [火山引擎控制台](https://console.volcengine.com/) 中复制视觉模型或推理接入点的调用配置。常用网关地址为 `https://ark.cn-beijing.volces.com/api/v3/chat/completions`。模型栏填写该接入配置要求的模型或接入点 ID。[火山方舟接口说明](https://docs.volcengine.com/docs/ark/chat-api?lang=zh)

### 硅基流动

在 [硅基流动控制台](https://cloud.siliconflow.cn/) 中选择支持图片输入的模型并复制完整模型 ID。常用网关地址为 `https://api.siliconflow.cn/v1/chat/completions`。以服务商提供的调用配置为准。[硅基流动视觉模型说明](https://docs.siliconflow.cn/docs/userguide/capabilities/vision)

## 多服务商管理

1. 在 **AI → 供应商与模型** 点击「添加供应商」，填写名称。已有「OpenAI兼容」配置也可以直接选中编辑。
2. 填写「服务网关 URL」和「API 密钥」，在「模型列表」下填写模型 ID，点击「添加」。确认供应商和模型都加在正确的位置。
3. 到 **AI → 批改工作流** 新建或编辑工作流，选中对应的供应商和模型。保存工作流，把它选为当前工作流，再点击「保存并启用」。

「供应商」下拉框用于选择要编辑的服务。每个方案实际使用的模型由[当前工作流](./workflow)决定。启用双评时，请同时检查主模型、副模型和仲裁模型的供应商与密钥。

## 流式输出

批改时，助手会在适用的窗口中显示正在返回的内容。评分完成后，可在提交窗口查看最终结果。显示内容取决于模型、工作流和[输出模式](/config/#输出模式)。

## 调整回答长度

模型、思考参数和回答长度按工作流设置。若评分回复经常截断或缺少分数，可在工作流中查看[限制单次回答长度](./workflow#限制单次回答长度)。

## 连接排查

- **连接未通过**：检查账号是否完成授权，或重新复制供应商密钥。用官方服务时可再点「测试线路」。
- **线路连得上，批改请求未通过**：检查余额、工作流中的模型 ID 和该账号的模型权限。自定义服务还需核对网关地址和图片输入支持。
- **暂时无法连接**：检查网络。使用官方服务时可测试其他线路。
